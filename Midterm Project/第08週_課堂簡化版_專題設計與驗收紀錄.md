## 二、輸出欄位契約

| 欄位名稱 | 型別／限制 | 用途 | 畫面標籤 | 如何查原文 |
|---|---|---|---|---|
| `sentiment` | `str`，必填 | 判斷評論的正面、負面或中立情緒 | 評論情緒 | 根據評論中的稱讚、抱怨及整體語氣核對 |
| `advantages` | `list[str]`，必填，可為空清單 | 整理商品優點 | 商品優點 | 逐項確認評論是否明確提到 |
| `disadvantages` | `list[str]`，必填，可為空清單 | 整理商品缺點 | 商品缺點 | 逐項確認評論是否明確提到 |
| `suggestions` | `list[str]`，必填，可為空清單 | 根據商品問題提出改善建議 | 改善建議 | 確認建議是否對應評論中實際提到的問題 |

所有欄位均為必填，禁止多餘欄位。清單內不得包含空白字串。

### 反思

**最有用的欄位：** `disadvantages`（商品缺點）。此欄位可以幫助賣家快速了解顧客不滿意的地方，作為商品改善的參考。

**遇到的問題：** 一開始執行到教師範例的 `app.py`，網頁顯示「課堂筆記重點整理器」。後來確認學生專題位於 `week08_midterm_simple_pydantic_starter`，改用正確檔案後成功啟動。

**已知限制：** 目前僅支援貼上文字，無法直接上傳評論檔案；AI 產生的內容仍需人工核對，且呼叫 API 可能產生費用。

**下一步：** 完成 Streamlit Community Cloud 部署、設定 Secrets、進行正常與資訊不足的真實 API 測試，記錄實際結果並確認老師可以開啟 App。

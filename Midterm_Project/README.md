# AI 商品評論分析系統

第 8 週生成式 AI 期中個人專題

## 一、專題介紹

本專題使用 Python、Streamlit、OpenAI API 與 Pydantic 開發商品評論分析系統，協助商家快速整理顧客的商品評論。

## 二、主要功能

1. **評論情緒分析**：判斷評論屬於正面、負面或中立。
2. **商品優點分析**：整理顧客提到的商品優點。
3. **商品缺點分析**：找出顧客反映的商品問題。
4. **改善建議**：根據評論內容提出改善方向。

## 三、使用技術

- Python
- Streamlit
- OpenAI API
- Pydantic Structured Outputs
- python-dotenv

採用教師提供的 Pydantic starter 修改，利用固定欄位格式輸出分析結果。

## 四、操作方式

1. 開啟系統網址。
2. 勾選「啟用真實 API」。
3. 在文字框貼上商品評論。
4. 點擊「處理資料」。
5. 查看評論情緒、商品優點、商品缺點及改善建議。

真實 API 請求可能產生費用。

## 五、本機啟動方式

安裝所需套件：

```bash
pip install -r requirements.txt
```

啟動 Streamlit：

```bash
streamlit run app.py
```

使用真實 API 前，須自行設定 `OPENAI_API_KEY`，可選擇設定 `OPENAI_MODEL`。請勿將真實金鑰上傳 GitHub。

## 七、測試與驗收結果

### 測試一：正常商品評論

輸入：

> 我買了這款藍牙耳機，音質清晰、配戴舒適，但電池續航力只有三小時，希望廠商能改善電池容量。

實際分析結果：

- 評論情緒：中立
- 商品優點：音質清晰、配戴舒適
- 商品缺點：電池續航力只有三小時、電池容量不足
- 改善建議：改善電池容量、提升續航時間

**結果：** 雲端真實 API 成功，輸出內容與原文相符或有合理依據。

### 測試二：資訊不足

輸入：

> 我今天去商店買了一個商品。

實際分析結果：

- 評論情緒：中立
- 商品優點：原文沒有對應項目
- 商品缺點：原文沒有對應項目
- 改善建議：原文沒有對應項目

**結果：** 雲端真實 API 成功，沒有編造商品優點、缺點或改善建議。

## 八、已知限制

- 系統僅分析使用者提供的文字，不會自動搜尋商品資料。
- AI 的分析仍需人工核對。
- 真實 API 呼叫可能產生費用。
- 空白輸入、過長輸入及 API 失敗處理等情境尚待完整驗收。
